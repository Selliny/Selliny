## 🚀 Projetos em destaque

### FarmHive — Do hardware à nuvem

Projeto acadêmico de uma rede IoT de baixo custo para coleta, transmissão e armazenamento de dados.

Desenvolvi o backend em Java com Spring Boot, atuando como camada intermediária entre:

- Aplicação mobile em Ionic
- Dispositivos ESP32
- Comunicação via MQTT
- AWS IoT Core
- AWS Lambda
- Amazon S3

Também projetei e documentei a API REST utilizando Swagger/OpenAPI.

**Tecnologias:**

`Java` `Spring Boot` `MQTT` `ESP32` `AWS IoT Core` `AWS Lambda` `Amazon S3` `Swagger`

### BridgeLibras

Plataforma de acessibilidade voltada à tradução de texto, áudio e gestos para Libras.

A solução utiliza Python e técnicas de processamento de imagens, áudio e linguagem natural para auxiliar na comunicação com pessoas surdas ou com deficiência auditiva.
